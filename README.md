# Ruby入門 オブジェクト指向編

Rubyの強みのひとつである**オブジェクト指向プログラミング**を、基礎から実践まで学ぶための学習シリーズです。

クラスやインスタンスといった基本から、継承・モジュール・メタプログラミングまで、実際に動かせるサンプルコードを交えながら解説します。

「オブジェクト指向って難しそう…」と思っている方でも、Rubyらしい柔らかい書き方と身近な例を通して理解できる内容になっています。

このシリーズを通して、オブジェクト指向の考え方とRubyでの実装方法をしっかり身につけましょう。

---

## 対象者

- Rubyの基本文法は理解している
- Rubyらしいオブジェクト指向を学びたい
- クラスや継承をしっかり理解したい
- Railsを書いているが、内部の仕組みも理解したい
- method_missingやDSLの仕組みに興味がある

---

## このシリーズで学べること

- オブジェクト指向とは何か
- クラスとインスタンスの違い
- アクセサメソッドと属性管理
- クラスメソッドと定数
- 継承とメソッドオーバーライド
- モジュールとMix-in
- メソッド探索ルート
- method_missingの仕組み
- DSLの基本的な考え方

## 学習の進め方

おすすめは次の順番です。

1. YouTubeで全体像を理解する
2. GitHubのREADMEで内容を復習する
3. サンプルコードを実際に動かしてみる
4. noteで詳しい解説を読む（準備中）

知識を「見る」だけではなく、「動かして理解する」ことで、オブジェクト指向への理解がより深まります。
